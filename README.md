# Discord Voice Channel Notification Bot

複数のDiscordサーバーでボイスチャンネルの参加・退出・移動を通知するボットです。

## 機能

- 🔊 ボイスチャンネルの参加・退出・移動を自動通知
- 🌐 複数サーバー対応
- ⚙️ サーバー毎の個別設定
- 🕐 タイムゾーン対応
- 🎛️ 通知の有効/無効切り替え
- 💬 わかりやすい日本語メッセージ
- 🔄 **設定の動的再読み込み（再起動不要）**
- 🔒 **スレッドセーフな設定管理**
- 🧩 **Cogベースのモジュラー構成**
- 📊 **安全な情報コマンド**
- 🔒 **セキュリティ強化**

## セットアップ

### 1. 必要なパッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. 環境変数の設定

以下の環境変数を設定してください：

```bash
# 必須：Discord Botのトークン
export BOT_TOKEN=your_bot_token_here

# オプション：管理者専用コマンドを使用する場合
export BOT_ADMIN_IDS=123456789012345678,987654321098765432
```

**重要**: `BOT_ADMIN_IDS`は管理者のDiscord IDをカンマ区切りで指定します。設定しない場合、管理者専用コマンドは使用できません。

### 3. ボットの起動

```bash
python bot.py
```

## 使用方法

### 初期設定

1. ボットをサーバーに招待
2. 通知を受け取りたいチャンネルで `!setup` コマンドを実行
3. 設定完了！

### コマンド一覧

### 設定コマンド

| コマンド | 説明 | 必要権限 |
|---------|------|---------|
| `!setup [#チャンネル]` | 通知チャンネルを設定 | サーバー管理 |
| `!enable` | 通知を有効化 | サーバー管理 |
| `!disable` | 通知を無効化 | サーバー管理 |
| `!status` | 現在の設定を確認 | なし |
| `!timezone <オフセット>` | タイムゾーンを設定 | サーバー管理 |
| `!reload` | 設定を手動再読み込み | サーバー管理 |

### 情報コマンド

| コマンド | 説明 | 必要権限 |
|---------|------|---------|
| `!vcstats` | ボイスチャンネル統計 | なし |
| `!version` | バージョン情報 | なし |
| `!help` | ヘルプを表示 | なし |

### 管理者専用コマンド

| コマンド | 説明 | 必要権限 |
|---------|------|---------|
| `!admin_info` | システム情報（隠しコマンド） | 管理者 |
| `!admin_servers` | サーバー一覧（隠しコマンド） | 管理者 |

### 設定例

```bash
# 現在のチャンネルを通知先に設定
!setup

# 特定のチャンネルを通知先に設定
!setup #voice-log

# 現在の設定を確認
!status

# 通知を無効化
!disable

# 通知を有効化
!enable
```

## ファイル構成

```

├── bot.py                    # メインボットファイル
├── cogs/                     # Cogパッケージ
│   ├── __init__.py
│   ├── config_cog.py        # 設定関連コマンド
│   ├── voice_cog.py         # ボイスチャンネル処理
│   └── utility_cog.py       # 情報・ユーティリティコマンド
├── config.json              # 設定ファイル（自動生成）
├── config.json.template     # 設定ファイルのテンプレート
├── requirements.txt         # Python依存関係
├── Dockerfile              # Docker設定
└── README.md               # このファイル
```

## 設定ファイル

`config.json` ファイルでサーバー毎の設定を管理します。

```json
{
    "servers": {
        "サーバーID": {
            "channel_id": "通知チャンネルID",
            "enabled": true,
            "timezone_offset": 9
        }
    },
    "default_settings": {
        "enabled": true,
        "timezone_offset": 9
    }
}
```

## Docker使用

```bash
# Dockerイメージをビルド
docker build -t discord-voice-bot .

# コンテナを起動
docker run -e BOT_TOKEN=your_token_here discord-voice-bot
```

## 必要な権限

ボットに以下の権限を付与してください：

- メッセージを送信
- メッセージ履歴を読む
- 埋め込みリンク
- ボイスチャンネルの状態を表示

## 重要な改善点

### 🔄 動的設定再読み込み
- **再起動不要**：サーバー設定を変更しても、ボットを再起動する必要がありません
- **自動監視**：設定ファイルの変更を30秒ごとに自動チェック
- **手動再読み込み**：`!reload` コマンドで即座に設定を反映可能

### 🔒 スレッドセーフな設定管理
- **競合状態の回避**：複数サーバーからの同時アクセスでも安全
- **データ整合性**：設定の読み書きが確実に同期される
- **エラーハンドリング**：設定ファイルの破損や読み込みエラーに対応

### 💾 設定の自動バックアップ
- **設定の永続化**：すべての設定変更が自動的にファイルに保存
- **エラー耐性**：設定ファイルの読み込みに失敗してもデフォルト設定で継続

### 🧩 Cogベースのモジュラー構成
- **ConfigCog**：設定関連のコマンドを管理
- **VoiceCog**：ボイスチャンネルイベント処理
- **UtilityCog**：情報・ユーティリティコマンド
- **コードの分離**：機能別にコードが整理され、保守性が向上
- **拡張性**：新しい機能を簡単に追加可能

### 🔒 セキュリティ強化
- **情報漏洩の防止**：システム詳細情報を一般ユーザーに公開しない
- **管理者専用機能**：センシティブな情報は管理者のみアクセス可能
- **隠しコマンド**：管理者専用コマンドはヘルプに表示されない
- **環境変数管理**：管理者IDを環境変数で安全に管理

## よくある質問（FAQ）

### Q: 設定を変更した後、ボットを再起動する必要はありますか？
A: **不要です**。v2.1.0以降では設定が自動的に再読み込みされます。手動で即座に反映したい場合は `!reload` コマンドを使用できます。

### Q: 複数のサーバーで同時に使用できますか？
A: **はい**。各サーバーで個別に設定を行うことで、複数のサーバーで同時に使用できます。

### Q: 設定ファイルを直接編集できますか？
A: **はい**。`config.json` ファイルを直接編集することも可能です。変更は最大30秒以内に自動的に反映されます。

### Q: 設定が正しく反映されない場合は？
A: `!reload` コマンドを試すか、`!status` コマンドで現在の設定を確認してください。

## トラブルシューティング

### 設定ファイルが破損した場合
- ボットは自動的にデフォルト設定で動作を継続します
- `!setup` コマンドで再設定を行ってください

### 権限エラーが発生する場合
- ボットに「メッセージを送信」「メッセージ履歴を読む」「埋め込みリンク」「ボイスチャンネルの状態を表示」権限が付与されているか確認してください

### 通知が届かない場合
- `!status` コマンドで設定を確認してください
- 通知チャンネルが削除されていないか確認してください
- `!enable` コマンドで通知が有効になっているか確認してください

### 管理者専用コマンドが使用できない場合
- `BOT_ADMIN_IDS` 環境変数が正しく設定されているか確認してください
- 自分のDiscord IDが正しく含まれているか確認してください
- 環境変数を変更した場合、ボットを再起動してください
